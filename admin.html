Primo accesso

Per gestire il sito serve un token GitHub (lo crei una volta sola, resta salvato su questo dispositivo):
  1. Apri github.com → nuovo token
  2. Repository access: Only select repositories → sito-san-grato
  3. Permissions → Contents: Read and write
  4. Expiration: scegli 90 giorni o più
  5. Genera e incolla qui sotto:

Chiama il cameriere

Stato sezione ···
Dopo ogni modifica il sito si aggiorna in 1-2 minuti (build di GitHub Pages). Senza URL backend la sezione non appare anche se attiva.
